# Scene 11 — Specimen Plate Geometry Refinement

**Scope:** Geometry-only refinement of the Scene 11 (`ACT 11 · EXPECTED SPECIES`) specimen plates and image aperture in `frontend/src/visual/ExpectedSpecies/`.

---

## 1. Old Geometry

- **Outer plate:** Conventional rectangular CSS box (`rounded-[2px] border border-[#D8D4C8]/26 bg-[#080909]` on the active plate; `rounded-[2px] border border-[#D8D4C8]/12 bg-[#050606]` on inactive stacked plates) with rectangular `box-shadow` depth.
- **Image aperture:** Conventional rectangular inner frame (`rounded-[2px] border border-[#D8D4C8]/12` wrapping a `rounded-[1px]` container with four rectangular corner ticks).

---

## 2. New Geometry

Replaced the rectangular box silhouette with a deterministic 3-variant asymmetric archival plate family generated by `buildSpecimenPlateGeometry` (`frontend/src/visual/ExpectedSpecies/specimenPlateGeometry.ts`):

- **Active Plate (`variant = "active"`):**
  - Top-left shallow archival bevel (`cutX = min(18, 0.062w)`, `cutY = min(22, 0.056h)`) with soft `3px` G1-continuous quadratic Bezier corner fillets.
  - Bottom-right subtle opposing bevel (`cutX = min(12, 0.042w)`, `cutY = min(14, 0.036h)`, `r = 2.5px`).
  - Top-right and bottom-left small-radius archival corners (`r = 3px`).
- **Inner Image Aperture (`isAperture = true`):**
  - Mirrors the active plate's opposing top-left (`min(12, 0.045w) × min(14, 0.048h)`) and bottom-right (`min(9, 0.034w) × min(10, 0.034h)`) soft bevels so the specimen photograph inherits the exact plate silhouette without cropping the subject.
  - Registration corner ticks are restricted to the uncut top-right and bottom-left corners.
- **Inactive Neighbor Plates (`variant = "left"` / `"right"`):**
  - Left-side plates (`offset < 0`): top-left (`min(12, 0.21w) × min(16, 0.045h)`) and bottom-left (`min(8, 0.14w) × min(11, 0.031h)`) soft archival bevels.
  - Right-side plates (`offset > 0`): mirrored top-right and bottom-right soft archival bevels.

---

## 3. Implementation Method

- **Single Unified SVG Silhouette & Perimeter Border (`SpeciesSpecimen.tsx` + `specimenPlateGeometry.ts`):**
  - Renders per-specimen `<clipPath clipPathUnits="objectBoundingBox">` definitions (`#eco-plate-clip-*` and `#eco-aperture-clip-*`) applied via CSS `clipPath` / `WebkitClipPath` to both the outer plate body and the inner image aperture.
  - Replaces rectangular CSS `border` and `box-shadow` with:
    1. A full-size SVG perimeter `<path>` (`strokePath`, inset `0.65px` with `vectorEffect="non-scaling-stroke"`) that traces the exact asymmetric bevels and soft fillets in active, hover, and focus states (plus a subtle secondary halo stroke on the active plate).
    2. A matching SVG perimeter `<path>` for the inner image aperture.
    3. CSS `filter: drop-shadow(...)` on the plate button so depth shadows follow the clipped silhouette rather than a rectangular bounding box.
- **Unchanged Layers:** Shared WebGL background (`EcologicalField`), Scene 12, ecological data, typography, palette, and 3D stack transforms (`computeArchiveSlotTransforms`) were not modified.

---

## 4. Responsive Behavior

`resolveSpecimenCorners` scales cut depths proportionally with `widthPx` and `heightPx` (capped for desktop and compacted for mobile):
- **Desktop (`1440×900`, `1920×1080`):** Active plate `296×396 px` (`18×22 px` top-left cut, `12×14 px` bottom-right cut); neighbor spines `58×362 px` (`12×16 px` / `8×11 px` edge cuts).
- **Mobile (`390×844`, `412×915`):** Active plate `226–239×316 px` (`14×18 px` top-left cut, `9×11 px` bottom-right cut); neighbor spines `44×276 px` (`9×12 px` / `6×9 px` edge cuts). Header (`pl-2`) and footer (`pr-2`) clearances keep `PLATE · XX` and `NOTE · XX →` unclipped on all viewports with zero horizontal overflow.

---

## 5. Interaction Preservation

- Clicking inactive neighbor plates still selects and centers that specimen.
- Clicking the active specimen plate still opens the existing `SpeciesFieldNote` dialog (`role="dialog"`) with full ecological context, epistemological boundary, and `Return to Archive` focus restoration.
- Keyboard left/right/Enter navigation, horizontal wheel/drag scrubbing, and `reducedMotion` mode remain unchanged. (Active-plate reveal animation was adjusted to animate `opacity` and `scale` inside the clipped aperture so WAAPI never overrides the SVG `clipPath`.)
