# ECOsonic 3.0 — OriginKit Component Adaptations (`ACT 02 → ACT 10`)

Complete accounting of every template component under [`components/originkit/`](../components/originkit/)—what architectural primitives were adapted into ECOsonic 3.0's shared WebGL stage and which SaaS/wellness wrappers, dependencies, and textures were rejected.

## 2. Rejected Components & Excluded Artifacts

All SaaS wrappers, brand assets, dead duplicates, and consumer UI components from OriginKit are explicitly excluded from production bundles:

1. **[`components/originkit/features-02.tsx`](../components/originkit/features-02.tsx) & `presence-01.css`** — Rejected SaaS "Connecting Worldwide Teams" copy, 3-card metrics strip, and `globe-icon.svg`.
2. **[`components/originkit/hero-19.tsx`](../components/originkit/hero-19.tsx), `section-26-hero.tsx`, & `hero-19.css`** — Rejected consumer wellness hero layout, Figma pixel coordinates (`top-[499px]`), Google Font `@import` overrides, hand/lamp PNGs, and standalone renderer.
3. **[`components/originkit/ui/hero-19/logo-marquee.tsx`](../components/originkit/ui/hero-19/logo-marquee.tsx)** — Rejected horizontal SaaS partner logo marquee (`animate-trusted-marquee`).
4. **[`components/originkit/ui/hero-19/recommendation-card.tsx`](../components/originkit/ui/hero-19/recommendation-card.tsx)** — Rejected consumer card UI primitive.
5. **[`components/originkit/ui/hero-19/particlesphere.tsx`](../components/originkit/ui/hero-19/particlesphere.tsx)** — Rejected unimported duplicate (`1,499` lines).
6. **[`components/originkit/hero-38.tsx`](../components/originkit/hero-38.tsx), `section-hero.tsx`, & `hero-38.css`** — Rejected Origin PR-review SaaS hero copy, `runPageScript` DOM injection, fake `createPortal` adapter, custom `IntersectionObserver` scroll/resize shim, and `Arial` CSS overrides.
7. **`public/originkit/` static images** (`arcs-desktop.png`, `bg-shapes-desktop.png`, `ipad-texture.png`, `hand*.png`, `tree.png`, etc.) — Never imported or bundled by Vite (`dist/` contains zero OriginKit textures).
